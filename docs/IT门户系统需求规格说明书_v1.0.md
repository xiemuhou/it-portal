# IT 门户与运维管理系统需求规格说明书

版本：v1.0  
日期：2026-10-21  
状态：当前开发基线

## 1 文档目的

本文汇总项目从最初规划到当前开发阶段已确认的全部有效需求，作为后续验收、维护、优化和迁移的统一依据。早期设计中已经取消或被新需求替代的内容不再作为建设范围。

系统面向公司员工和 IT 运维团队，提供公开 IT 门户、工单协作、知识库、公告、网络基础台账、静态 IP 管理、电脑资产管理、组织人员同步、角色权限和操作审计功能。

## 2 建设目标

1. 让员工了解 IT 部门提供的服务、运维范围和工作成果，并能通过统一入口提交及跟进问题。
2. 将工单、网络台账、静态 IP 和电脑资产从分散 Excel 管理逐步迁移为数据库在线维护。
3. 通过工单分类、处理轮次和处理人分段记录体现 IT 运维工作量，但不把处理历时描述为实际人工投入工时。
4. 对内部台账、人员、权限和审计信息实施登录及角色权限控制，对公告、知识库、服务目录和运维态势入口提供公开访问。
5. 正式支持 Windows + SQL Server 和 Linux + MySQL 两条部署路径，并支持从空数据库初始化或将 SQL Server 数据离线迁移到 MySQL。

## 3 系统边界

### 3.1 本期范围

- 公开门户、公告、知识库、服务目录、网络运维态势入口。
- 应用账号登录、密码修改、用户、部门、岗位、角色与权限。
- 工单提交、分配、接单、转派、关闭、取消、重开、纠正、留言、附件和统计。
- 提交工单前的 AI 自助对话、已发布知识推荐，以及管理员维护 OpenAI 兼容接口配置。
- VLAN、Wi-Fi、网络设备、带宽线路、VPN 隧道五类基础信息台账。
- 耗材目录、采购入库、领用出库、库存预警和不可覆盖的出入库流水；出库可关联电脑或独立登记领用对象。
- IT 备忘录，供管理员和 IT 人员保存零散系统信息和加密账号凭据。
- 选定静态 IP 网段的地址占用管理，以及电脑设备台账和二者双向关联。
- 标准 Excel 模板导入导出、EHR 只读同步、LDAP/Active Directory 只读同步。
- 站内消息和操作审计。
- 快捷链接管理和按角色显示。

### 3.2 不在当前范围

- 不重新开发网络监控系统，只提供现有系统的新窗口入口。
- 不把旧异形 Excel 和 OneDrive 工作表作为正式数据库的持续覆盖数据源。
- 不建设邮件、短信、企业微信等外部通知。
- 不建设工单满意度、复杂 SLA、审批流和自动关单。
- 不从工单自动生成知识文章。
- 不要求移动端适配；页面以桌面端使用为主。
- LDAP/Active Directory 未启用时不连接域服务，启用后只执行目录搜索，不修改域对象。AI 助手未启用时不连接外部服务；启用后只发送当前临时对话和匹配知识的标题、摘要、正文片段与站内链接，不发送完整源文件。

## 4 用户和权限

### 4.1 用户类型

| 用户类型 | 主要能力 |
|---|---|
| 未登录访问者 | 查看服务概览、已发布公告、公开知识库、服务目录和网络运维态势入口 |
| 普通员工 | 提交和查看本人工单、留言、查看站内消息、使用通用快捷链接、修改本人密码 |
| IT 运维 | 处理工单、查看运维统计、维护授权范围内的台账、IP 和电脑资产、维护知识内容 |
| 管理员 | 管理用户、部门、岗位、角色权限、公告、分类、服务目录、AI接口和审计，并拥有授权范围内的全部业务能力 |

### 4.2 权限模型

权限由“模块操作权限”和“数据范围”共同决定。数据范围支持本人、当前负责、指定区域、指定部门和全部。用户可拥有多个角色，但不同操作的范围不能交叉拼接产生越权。

菜单、按钮、接口、附件、预览、导入、导出和报表必须使用相同的服务端授权规则。系统应保护最后一个有效管理员，禁止把全部管理员停用或删除。

### 4.3 账号和密码

- 管理员创建账号和初始密码，创建后可以直接登录，不设置激活流程。
- 密码长度至少 8 位，不强制大小写、数字和特殊字符组合。
- 用户可使用当前密码修改本人密码；管理员可为用户设置新密码。
- 数据库只保存密码哈希，不允许查询现有明文密码。
- 改密、停用或权限调整后，旧会话失效。
- 会话最长 8 小时，连续空闲 10 分钟退出；后台轮询不延长空闲时间。

## 5 信息架构和界面

### 5.1 菜单结构

| 分组 | 菜单 |
|---|---|
| 员工服务 | 服务概览、提交工单、知识库、公告、服务目录、网络运维态势、快捷链接 |
| 协作与运维 | 工单工作台或我的工单、运维分类汇总、基础信息台账、静态 IP 管理、电脑设备台账 |
| 管理中心 | 部门与人员、角色与权限、公告管理、知识管理、基础资料、操作审计 |

菜单根据当前用户权限动态显示。网络运维态势和快捷链接使用新窗口打开。

### 5.2 通用交互

- 系统以桌面端 1440 至 1920 像素宽度为主要使用环境，不要求手机布局。
- 菜单字号保持清晰，内容区可适当紧凑，但不得影响表格和表单可读性。
- 列表默认每页 10 条，可选择 10、20 或 50 条，并提供上一页、下一页和指定页跳转。
- 数据量较多的下拉框支持输入关键词进行模糊搜索。
- 停用、异常、待确认、冲突等状态使用颜色或图标区分。
- 新增和编辑页面不展示内部 UUID；需要业务编号时由系统生成。
- 删除操作要求明确原因或确认信息；存在业务引用时应阻止删除并提示处理方法。

## 6 公开门户

### 6.1 服务概览

首页展示已发布公告、常用知识、IT 服务范围、提交工单入口、快捷入口以及 IT 运维价值信息。没有真实数据时显示暂无数据，不使用示例内容冒充生产数据。

### 6.2 网络运维态势

菜单直接打开已配置的现有网络运维态势系统。门户不代理其登录、不抓取页面数据，也不承担监控系统权限控制。

### 6.3 服务目录

服务目录用于说明 IT 能提供哪些服务、适用范围、服务时间、申请方式和注意事项。管理员维护并公开发布。当前建议服务包括：

- 账号与权限：账号开通、权限申请、密码和登录问题。
- 电脑与软件：电脑故障、办公软件、软件安装和终端配置。
- 网络连接：有线网络、无线网络、VPN、网络访问和 IP 申请。
- 打印与会议：打印机、扫描仪、投影、会议室终端和音视频问题。
- 文件与系统：共享目录、业务系统访问、文件恢复和数据协作。
- 信息安全：病毒、钓鱼邮件、异常账号、终端安全和数据安全协助。
- 其他 IT 支持：不能归入以上分类的 IT 服务。

### 6.4 快捷链接

- 快捷链接分为“通用”和“IT 管理”两类。
- 员工只能看到通用链接；IT 和管理员可以看到全部链接。
- 管理员可维护标题、URL、图标文字、说明、分类、启用状态和排序。
- 所有链接在新窗口打开。

## 7 公告和站内消息

### 7.1 公告

- 公告由管理员在线新增、编辑、发布、撤下和删除，不提供导入导出。
- 字段包括标题、正文、置顶、发布状态、发布时间、可选截止时间、发布人和附件，不设置摘要字段。
- 截止时间在界面显示到分钟。
- 管理列表可筛选已发布和草稿，按发布时间倒序显示。
- 公开端只显示已发布且未过期公告，置顶内容优先。
- 发布后的公告必须显示发布人。
- 附件最多 10 个，单个不超过 20 MB；支持常见文档、图片、文本和 ZIP。
- 已发布公告如需修改附件，应先撤下，编辑完成后重新发布。
- 公开公告附件支持在线查看和下载。

### 7.2 站内消息

- 站内消息入口位于页面右上角，使用数字显示未读数量，超过 99 可显示为 99+。
- 支持单条已读和一键全部已读。
- 公告每次发布后，所有有效账号收到站内消息。
- 工单提交、接单、分配、转派、关闭、重开和相关业务事件可以产生站内消息。
- 消息只提供入口，用户打开目标内容时仍需重新鉴权。

## 8 知识库

- 知识库阅读不区分员工角色，已发布内容允许公开查看。
- 管理端只允许上传文件建立知识文章，不提供“接入已有手册”入口。
- 支持 HTML、HTM、PDF、PPT 和 PPTX，单个文件不超过 20 MB。
- 文章维护分类、标题、版本、发布状态、更新时间和查看次数。
- 上传新版本不得覆盖历史版本；发布和撤下是独立操作。
- 点击阅读后在新窗口打开。HTML 按原文件展示；PDF 和 PPT/PPTX 使用连续页面阅读，不提供门户翻页按钮和源文件下载按钮。
- PPT/PPTX 需要 PowerPoint 或 LibreOffice 转换为静态预览，动画和音视频不保证保留。
- 系统记录文章查看次数。
- 工单提交页面先检索已发布知识的标题、摘要和可提取正文，再按管理员设置的严格知识库、混合或通用模式调用 OpenAI 兼容 API。无匹配时可提供安全通用建议或直接引导提单；推荐失败不能阻止工单提交。

## 9 工单系统

### 9.1 提交

- 提交工单必须登录。
- 用户至少填写问题描述，标题可由描述生成或手动调整；区域、位置和联系方式可选。
- 提交前提示用户先查看知识库，并显示关键词推荐结果。
- 系统生成唯一工单号，使用幂等机制防止重复提交。
- 工单提交人显示所属部门，并保存提交时的姓名和部门快照。

### 9.2 状态和流程

| 状态 | 说明 |
|---|---|
| 待接单 | 工单已提交，可预分配负责人，但尚未开始处理 |
| 处理中 | IT 接单后进入，记录本轮开始时间 |
| 已关闭 | IT 完成处理，选择分类和实际结束时间后关闭 |
| 已取消 | 工单无需继续处理，保留取消原因 |

IT 可以接单、预分配和转派给具备处理权限的同事。处理中转派时结束原处理人的分段并开始新处理人的分段。多人同时接单只能有一人成功。

### 9.3 关闭和计时

- 只有处理中工单可以正常关闭。
- 关闭时必须选择问题分类，填写实际结束时间，处理说明可选。
- 实际结束时间只要求晚于工单提交时间，不再限制必须晚于最后一次接单或转派，也不限制必须早于当前时间。
- 界面时间显示到分钟，不显示秒和毫秒。
- 系统保存实际结束时间和系统关闭时间，并重新计算各处理分段；发生在实际结束时间之后的分段按零时长处理。
- 处理历时包含等待或非工作时段，只表示流程历时，不等同实际劳动投入。
- 已关闭工单可重开，新建处理轮次；历史轮次保持不变。
- 有权限的管理员可纠正分类和实际结束时间，必须填写原因并保留审计。

### 9.4 留言和附件

- 工单发起人和有权限的 IT 均可留言。
- IT 可添加仅 IT 可见的内部备注。
- 关闭后仍允许留言，留言不改变工单状态和计时。
- 附件支持 PNG、JPG 和 PDF，单个不超过 20 MB；附件继承对应留言的可见范围。

### 9.5 分类和统计

- 工单分类由管理员或授权人员维护，可新增、修改、停用和删除。
- 被工单、历史周期或下级分类引用的分类不能删除，应改为停用。
- 服务目录与工单分类为独立模块，不允许切换服务目录后导致分类数据消失。
- 运维分类汇总按实际结束时间统计，包括关闭轮次、唯一工单数、分类数量、总及平均处理历时、最终结单数、参与处理轮次和个人分段历时。

## 10 部门 人员 岗位和 EHR 同步

### 10.1 部门与人员

- 部门、人员和岗位集中在独立“部门与人员”菜单。
- 部门显示部门编号、中文名称、上级部门、来源和状态；上级部门显示中文名称。
- 人员显示登录账号、姓名、所属部门、最上级部门、岗位、角色、来源和状态，并支持按部门筛选。
- 岗位只按岗位名称维护，不与部门建立固定从属关系；重复岗位去重。
- 手工新增部门、人员和岗位的能力保留。
- EHR 同步记录标记为“EHR 同步”，手工记录标记为“手工维护”。
- 删除门户中的 EHR 同步记录不能修改 EHR 源数据库。

### 10.2 EHR 只读同步

- EHR 使用独立只读连接，只允许查询 `V_Employee`、`V_Department` 和 `V_Employee_JOB` 三张视图。
- 部门只同步配置项 `ehr_org_code` 指定组织范围内的记录。
- 员工保留工号、姓名、部门编号和离职日期；岗位保留工号、部门编号和岗位名称。
- 工号作为登录账号和首次同步初始密码。
- 首次同步时在职人员启用，离职人员停用；后续新同步人员默认停用，离职人员强制停用。
- 页面提供手动同步按钮，系统每天 00:00 自动同步。
- 同步结果、错误和时间写入门户数据库；不得对 EHR 数据库执行 INSERT、UPDATE、DELETE 或 DDL。
- LDAP/域用户同步采用只读服务账号，支持 LDAPS/证书验证、连接测试、手动同步和可选的每日定时同步；未启用时不连接。
- 域用户按稳定对象标识优先对齐，再按工号或登录账号匹配现有门户人员；部门按名称复用或新增，岗位按名称去重。新增域用户默认停用，禁用的域账号会停用对应门户账号；同步不覆盖门户密码和角色，不修改域目录。
- LDAP 同步只负责组织资料同步，不等同于使用域密码登录门户；域认证需要单独设计和启用。

## 11 五类基础信息台账

五类台账共用资源权限、区域、启用状态、备注、版本控制、筛选、分页、导入导出和操作审计。列表保留关键词及区域筛选；新增页面不提供无意义的额外筛选，也不提供添加其他业务类型的入口。

### 11.1 VLAN 规划

- 字段顺序：区域、VLAN ID、网段列表、启用、备注。
- 一个 VLAN ID 可以包含多个网段，每个网段独立维护 CIDR、网关、用途和是否启用静态 IP 管理。
- 不维护 DHCP 起始和结束 IP。
- 列表按网段平铺显示，同一个 VLAN 的多个网段可显示为多行；编辑时仍统一维护同一 VLAN。
- 删除单个网段只删除该网段，不能删除整个 VLAN；被 Wi-Fi、VPN 隧道或静态 IP 引用时应阻止删除。
- VLAN ID 支持数字升序和降序；列表显示备注。
- 其他模块引用 VLAN 时按具体网段分开选择。

### 11.2 Wi-Fi 规划

- 字段包括区域、SSID、用途、覆盖位置、认证方式、密码、关联 VLAN 网段、关联 AP、启用和备注。
- 认证方式包括不认证、密码、密码加 MAC。
- 密码加密保存，管理端可按权限显示或隐藏；列表显示密码状态或按当前界面受控显示，导出不输出明文密码。
- 关联 VLAN 使用“区域 + VLAN ID + 网段”选择，并带出 CIDR、网关和用途。
- 列表显示密码信息和备注。

### 11.3 网络设备

字段顺序为：区域、设备类型、管理 IP、启用、设备型号、ESN、上联设备管理 IP、上联设备接口、本机上联接口、用户名、密码、安装位置、是否堆叠、维保开始、维保结束、备注。

- 新增和列表中的上联设备只显示管理 IP，并通过管理 IP 关联；导入也只要求上联设备管理 IP。
- 列表保留上联设备接口和本机上联接口，不显示 ESN。
- 不维护登记状态、管理 VLAN、责任人和位置类型；安装位置手工填写。
- 不维护堆叠说明，只记录是否堆叠。
- 登录密码加密保存，导出不输出明文。
- 停用设备在列表中使用明显状态样式。

### 11.4 带宽线路

- 字段包括区域、运营商、保障电话、主线或赠送线路、线路号、上下行带宽、月租费用、多个线路接入明细、光猫管理用户名和密码、到期时间、启用和总备注。
- 一组线路可包含多条主线或赠送线路。
- 每条线路可以添加多个接入明细，每个明细独立维护连接方式、IP、掩码、网关、接入接口、拨号账号、拨号密码和用途。
- 连接方式包括路由、桥接和拨号。拨号方式使用账号密码，可不填写静态 IP、掩码和网关。
- 列表以分组或合并单元格效果展示同一线路组下的多条线路与接入明细。
- 光猫和拨号密码加密保存，导出不输出明文。

### 11.5 VPN 隧道

- 字段包括区域、本地 VLAN 网段、本地网关、对端区域、对端 VLAN 网段、手工对端网段、隧道列表、启用和备注。
- 本地和对端 VLAN 都按具体网段选择，带出网段 CIDR 和用途；不存在 VLAN 时允许手工补充对端 CIDR 和备注。
- 不维护本地设备和独立用途字段。
- 每条连接最多登记两个隧道，登记状态为正常或停用，并用图标或颜色表示。
- 列表显示对端网段，格式为“用途或网段备注 - CIDR”。

## 12 静态 IP 管理

### 12.1 管理范围

- 只对 VLAN 规划中明确勾选“静态 IP 管理”的网段展开地址管理，不要求管理所有 VLAN。
- 自动识别网络地址、广播地址和网关；网关作为系统保留地址不能修改。
- 页面显示可管理地址、已占用、空闲、待确认、冲突和待核对资料数量，统计卡片保持紧凑。

### 12.2 IP 记录

字段包括 IP 地址、占用状态、确认状态、归属类型、部门、使用人、占用设备类型、MAC、位置、备注、关联电脑和具体网卡。

- 占用状态包括空闲、已占用、预留和冲突；确认状态包括待确认和已确认。
- 新记录未填写状态时默认空闲和待确认。
- 个人使用设备占用 IP 时必须选择系统人员，部门由人员自动带出，不允许手工输入。
- 公共设备不要求选择使用人，但可独立选择“管理/使用部门”，该部门不依赖人员，也不与公共电脑资产的空部门进行一致性比较；占用状态为已占用或冲突时必须填写占用设备类型。
- 公共设备在个人使用与公共归属之间切换时：切换为个人使用必须选择系统人员并以人员部门为准；切换为公共设备时清除使用人，并允许保留或重新选择管理/使用部门。
- 占用设备类型提供笔记本和台式机两个常用选项，并允许手工填写打印机、门禁、服务器等其他类型。
- 位置不是必填项。
- 释放按钮直接显示在列表操作区；释放后清除当前占用关系并保留历史。
- 电脑类设备未关联电脑资产时显示明显标识，便于核对。

### 12.3 与电脑资产关联

- 只有 IP 记录的 MAC 与电脑网卡 MAC 一致时才允许建立关联。
- 关联电脑时必须选择具体网卡，下拉项显示有线、无线、虚拟或其他网卡类型及 MAC。
- 关联后占用设备显示电脑的设备类型，不显示资产编号作为设备类型。
- 电脑台账显示与各网卡关联的 IP；在电脑中新增 IP 关联时，IP 管理同步占用该地址。
- MAC 匹配但部门、使用人、归属类型、设备类型或位置不一致时不自动覆盖，显示“资料不一致”及具体差异。

### 12.4 导入导出

静态 IP 模板列顺序为：区域、VLAN ID、网段、IP 地址、归属类型、部门、使用人、占用设备、MAC 地址、位置、备注、状态、确认状态。

导入使用区域、VLAN ID 和网段唯一定位受管网段。个人使用记录的人员必须匹配门户组织资料，部门必须与人员部门一致；人员不存在或已离职时允许导入，保留原姓名并进入待确认。公共设备部门按名称匹配系统部门，匹配成功后建立部门关联；部门不存在或不唯一时不阻断导入，保留 Excel 原始部门名称，标记“部门不存在”并进入待确认。状态和确认状态允许留空，分别默认为空闲、待确认。

## 13 电脑设备台账

- 电脑设备类型只允许笔记本和台式机。
- 字段包括资产编号、设备类型、验收日期、归属类型、区域、部门、使用人、位置、操作系统、状态、网卡、关联 IP、配件和备注。
- 验收日期精确到年月且不能晚于当前月份。系统按当前月份自动计算使用年限，显示为“X年X个月”；严格超过 60 个月时使用深色强调。
- 归属类型包括个人使用和公共设备。个人使用必须选择系统人员，部门自动带出；公共设备不要求人员和部门。
- 位置不是必填项。
- 网卡每行只维护网卡类型和 MAC，移除按钮放在同一行末尾。
- 配件每行只维护配件类型和备注，不单独维护品牌和序列号；移除按钮放在同一行末尾。
- 常见配件包括显示器、鼠标、键盘、移动硬盘和 U 盘，也允许录入其他类型。
- 电脑验收日期、使用人、部门、位置、配件和 IP/网卡关系变化应写入详细变更记录，明确显示修改前和修改后。
- 电脑可以删除，但存在静态 IP 关联时必须先释放或解除关联。
- 电脑支持标准模板导入导出。模板包括资产编号、设备类型、验收日期、归属类型、区域、部门、使用人、位置、操作系统、状态、网卡类型、MAC、关联 IP、配件类型、配件备注和电脑备注；验收日期使用 `YYYY-MM`。

## 14 耗材管理

### 14.1 耗材目录和库存

- 耗材目录字段包括耗材编码、名称、分类、规格型号、计量单位、最低库存、启停状态和备注；编码留空时由系统自动生成。
- 库存由全部有效出入库流水实时汇总，不维护可被直接修改的冗余库存数值。
- 当前库存小于或等于最低库存时显示预警；列表按所选月份统计采购入库量和领用出库量。
- 停用耗材保留历史数据，禁止继续入库和出库。
- 没有出入库流水的耗材品类可以删除；已有流水的品类只能停用，以保留库存历史。

### 14.2 采购入库和领用出库

- 采购入库记录入库日期、数量、采购单价、供应商、备注和操作人，不要求填写单据编号。
- 领用出库记录出库日期、数量、用途、单据编号、备注和操作人，库存不足时禁止提交。
- 领用出库可关联电脑，也可独立关联人员、部门，或填写打印机、会议室和公共设备等其他领用对象。
- 关联电脑时自动记录电脑当前使用人和部门，并在电脑详情的配件区域显示只读的耗材领用记录。
- 每个耗材均可分页查询完整流水；流水采用追加方式保存，业务记录不能直接覆盖。
- 原出库流水可执行一次返库，系统增加返库流水并恢复库存；关联电脑的耗材领用记录同时取消。
- 原入库流水可执行一次撤销，系统增加撤销流水并扣减库存；当前库存不足以扣回原入库数量时禁止撤销。

### 14.3 权限和审计

- 耗材模块包含查看、维护目录、采购入库和领用出库四项权限，默认授予管理员和 IT 角色。
- 新增和编辑目录、入库及出库操作写入操作审计；审计不记录密码或其他敏感明文。
- 并发出库通过耗材版本号进行冲突检测，确保同一库存不能被重复扣减。

## 15 IT 备忘录

- IT 备忘录用于保存零散的系统账号、网络设备、服务器、数据库和供应商平台信息，不包含待办、提醒或审批流程。
- 字段包括标题、分类、系统或设备地址、用户名、加密密码、标签和备注。
- 所有备忘录仅管理员和 IT 角色可见，不提供按记录选择可见范围的功能。
- 其他查看者不能修改或删除记录，只有创建人可以维护。
- 密码采用部署凭据密钥加密，列表、搜索、日志、导出和审计内容不得包含密码密文或明文。
- 密码通过独立接口按需解密，响应禁止缓存；密码查看不记录查看人和查看时间。
- 修改记录时密码留空表示保留原密码，也可以明确清除；删除记录时同步清除加密密码。
- 模块权限包括查看、编辑、查看密码和删除，默认授予管理员与 IT 角色，普通员工不显示入口。

## 16 导入导出

- 五类台账、静态 IP 和电脑设备提供各自标准 XLSX 模板。
- 每个业务字段占用独立列；存在一对多信息时允许同一主记录占多行或使用预定义重复列，不能使用难以维护的自由文本拼接。
- 导入前提供模板下载，上传后先进行预览和校验，再确认写入。
- 导入应在一个事务中完成；默认任一错误阻止整批提交，授权用户可明确选择只提交正确行。
- 更新记录按稳定业务键或明确的业务定位字段匹配，不依赖数据库 UUID。
- 导出只包含当前用户有权查看的字段，不包含密码、哈希、会话令牌或密钥明文。
- 公告、基础资料不提供通用导入导出入口。

## 17 数据库和技术要求

### 17.1 数据库

- Windows 现有环境使用 SQL Server `itPortal`；Linux 生产环境使用 MySQL 8.0/8.4。两端都通过 SQLAlchemy 和 Alembic 管理模型与迁移。
- 主键使用 UUID 字符串，新记录采用时间有序 UUIDv7。用户执行数据库插入时应由应用生成主键，不要求人工编写。
- MySQL 统一使用 `utf8mb4`，并保持毫秒时间精度、唯一约束、外键和事务一致性。
- SQL Server 到 MySQL 使用项目提供的离线迁移工具；源库只读，目标库必须为空，失败整体回滚，并逐表验证行数和摘要。迁移不能只修改连接串。

### 17.2 文件

知识原件、预览缓存、公告附件和工单附件存放在业务数据目录。数据库备份不包含这些文件。Wi-Fi、设备、线路和 IT 备忘录密码的加密密钥必须与数据库和文件一起纳入受控备份。

- 上传采用“临时文件、数据库 `pending`、事务提交、同盘原子重命名、`ready`”流程，读取接口只提供 `ready` 文件。
- 服务启动时及每天 02:30 执行文件一致性巡检；完整且可验证的 `pending` 文件自动恢复，缺失、哈希不一致和孤立文件只报告，不自动删除。
- 巡检报告保存到 `data/business/reports/file-integrity/`，管理员可通过维护接口读取最近报告或手动执行。

### 17.3 性能和稳定性

- 系统目标为公司内部小到中等并发；常用列表接口 P95 目标小于 500 毫秒。
- 分页、筛选和排序由服务端执行；高增长表应配置适当索引和归档策略。
- 数据库错误对前端显示统一提示，服务端应记录可定位的结构化日志，但不得记录密码和连接串。
- HTTP、数据库异常和后台任务使用 JSON Lines 结构化日志，日志保留 90 天。
- 操作审计和站内通知保留 180 天，每日维护任务按批次清理过期记录并留下新的维护审计。
- 健康检查应区分进程存活和数据库、文件目录等就绪状态。
- 正式部署使用服务守护和 HTTPS 反向代理；当前桌面开发启动方式不作为最终高可用方案。

### 17.4 备份

- 门户不提供数据库备份或恢复入口，应用账号不持有数据库备份与恢复权限。
- SQL Server由SQL Server Agent、维护计划或企业备份平台建立完整、差异和日志备份。
- 文件备份工具负责保护附件、知识文件和加密密钥，并与数据库备份形成同一恢复批次。
- 备份方案必须通过隔离环境恢复演练。

## 18 安全要求

- 所有 SQL 使用参数绑定；EHR 连接只允许固定 SELECT。
- 写操作校验 CSRF，Cookie 使用 HttpOnly、SameSite，HTTPS 部署启用 Secure。
- 文件上传检查扩展名、大小、文件签名和保存路径，禁止目录穿越。
- HTML 知识内容在隔离环境运行，不能读取门户 Cookie 或本地存储。
- 敏感密码只在授权详情中按需解密，不进入列表接口、导出文件和审计日志。
- 角色权限变更、工单关键操作、数据删除、发布、导入导出、同步和备份写入操作审计。

## 19 验收要求

1. 未登录用户只能访问公开内容，不能读取内部工单和台账。
2. 员工可提交、跟进、留言和重开本人工单，不能读取他人工单或内部备注。
3. IT 可按授权接单、转派、关闭并查看分类汇总；并发接单只能成功一次。
4. 管理员可管理用户、角色、公告、知识和组织资料，且不能删除最后一个管理员。
5. 五类台账字段、关联、删除保护、模板导入导出和密码保护符合第 11 节。
6. 静态 IP 只展开选定网段，MAC 是电脑关联的必要条件，资料不一致不得被静默覆盖。
7. 电脑个人和公共归属验证、网卡和配件维护、详细变更记录、IP 双向关系符合第 13 节。
8. 耗材可完成采购入库、独立或关联电脑出库，库存不足时阻止提交，且每项耗材的完整流水可追溯。
9. IT 备忘录仅管理员和 IT 人员可见，列表不返回密码，查看密码受权限控制且不生成查看记录。
10. EHR 同步只读且幂等，门户删除不影响 EHR 源数据。
11. 公告发布产生全员站内消息，知识查看计数正确，附件权限跟随业务状态。
12. 完整自动化测试通过；上线前完成备份恢复、HTTPS、服务守护、日志和告警验收。

## 20 后续预留

- LDAP/Active Directory 只读同步。
- 外部 AI 的向量检索、重排序和独立索引服务；当前版本使用本地关键词与正文片段匹配。
- MySQL 8 和 Linux 正式部署。
- EHR 集合式同步、通知批量分发、报表数据库聚合和大数据游标分页。
- 多实例部署时的数据库任务锁和共享文件存储。
