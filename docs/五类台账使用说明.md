# 五类台账使用说明

登录后选择“基础信息台账”，维护 VLAN 规划、Wi-Fi 规划、网络设备、带宽线路、VPN 隧道。列表保留关键词、区域筛选；新增和编辑表单不设置搜索框或独立名称，也不提供新增其他业务资料的入口。

## 状态与关联

启用记录使用绿色标识。停用记录使用“⏸ 已停用”橙色标识，并给整行使用浅色底纹；资料仍可查看和编辑，重新启用后恢复正常显示。新增关联不能选择停用或已归档资料，原有引用保留。

先维护区域和 VLAN，再维护引用它们的 Wi-Fi、AWS 等资料。修改被引用 VLAN 的网段或网关时需检查并确认影响；仅调整网段用途无需网络影响确认，关联 Wi-Fi、AWS 会同步显示更新后的用途。被引用资料不能删除，可以停用。VLAN 修改只更新台账，不向设备下发配置。

## VLAN 与 Wi-Fi

VLAN 填写区域、VLAN ID，并为每个网段分别填写 CIDR、网关和网段用途；同一 VLAN 下不同网段可以有不同用途。旧版统一用途会自动带入各个缺少用途的网段。列表按网段分行：同一个 VLAN 下有两个网段时显示两行，编辑按钮仍进入同一个 VLAN 的完整表单；每行的“删除网段”仅删除该网段，保留同一 VLAN 的其他网段；删除最后一个网段也保留空 VLAN ID。只有空 VLAN 行才提供“删除空 VLAN”按钮。服务端也禁止通过整个记录的旧删除接口删除仍有网段的 VLAN。列表按 VLAN ID 数字排序后按网段分页，并显示备注。独立网络中 VLAN ID 重复时可用高级选项区分网络范围，通常使用 default。

Wi-Fi 选择区域后，按“区域 · VLAN ID · 用途 - CIDR”选择具体网段，网段和网关自动带出。可只选同一 VLAN 的一个网段，也可用“添加网段”多选。认证方式为不认证、密码、密码+MAC；列表显示密码和备注，密码默认遮罩，点击显示或隐藏。不认证时不保存 Wi-Fi 密码。

## 网络设备

维护设备类型、型号 / 品牌、ESN码、上联设备及接口、管理 IP、用户名 / 密码、安装位置、是否堆叠、维保时间和备注。

新增、编辑的上联设备下拉选项只显示管理 IP；列表中的上联设备显示管理 IP，并在下方保留上联接口、本机接口。管理 IP 列位于设备类型之后。没有管理 IP 的上联设备显示“未登记管理 IP”。

ESN码保留在新增、编辑详情和标准模板中，列表不展示。不再维护登记状态、管理 VLAN、责任人、位置补充或堆叠说明；安装位置手填，堆叠仅选择是 / 否。既有后台责任归属保留，以维持原有权限范围。

导入时“上联设备”可直接填写同一区域内的管理 IP；兼容“型号 · 管理 IP”、记录编号和名称。关联必须唯一，重复 IP、跨区域、循环或关联自身会提示错误。同批新增设备会先处理上联设备，再处理下联设备，表格行无需排序。导出上联设备优先显示唯一管理 IP；未设置 IP 或 IP 不唯一时使用记录编号。

设备“仅新增”模式拒绝同一区域重复管理 IP。导入已有设备时选择“按编号或管理 IP 新增或更新”：优先按记录编号更新；编号留空时，按区域和管理 IP 唯一匹配已有设备，没有匹配才新增。数据库中已有重复 IP 时需保留导出编号，不能自动选择其中一台。预览不写入设备资料，确认提交才保存。

## 带宽线路

每组资料维护运营商、月租费用、保障电话、主线 / 赠送线路、光猫管理账号密码、到期时间及总备注。列表不显示月租费用、光猫账号密码和到期时间，可在详情中查看和维护。

每条主线或赠送线路维护自己的线路号和上下行带宽。在线路下点击“添加 IP / 接入信息”，可添加多条接入记录，每条独立填写连接方式、IP、掩码、网关、接入接口、拨号信息及用途：

- 路由：按需填写 IP、掩码、网关、接口和用途。
- 桥接：按需填写 IP、掩码、网关、接口和用途。
- 拨号：依次填写拨号账号、拨号密码和用途，可填写接入接口；隐藏且不保存固定 IP 参数。切换为路由或桥接后不保存拨号凭据。

列表中每条接入信息占一行，同一线路的线路号和带宽纵向合并；区域、运营商、保障电话、光猫信息等组公共资料再次合并。旧数据中同一线路的多个 IP 自动拆为多条接入记录，原连接方式、接口、用途和已加密拨号凭据保留，随后可逐条修改。

## VPN 隧道

选择本地区域及本地 VLAN 网段、对端区域及对端 VLAN 网段，两端都可以独立选择具体网段，不自动包含同 VLAN 下的其他网段。下拉选项显示 VLAN ID、网段和用途；关联网段直接使用 VLAN 规划中对应网段的用途，不再单独填写网段备注。没有对端规划时，可逐行手填对端 CIDR 和网段备注。

隧道不再单独维护用途、本地设备、承载线路或对端区域补充。本地和对端的 VLAN 网段下拉框均常驻提供 `Any - 0.0.0.0/0`；选择 Any 后，该侧只保留 Any，不再选择其他 VLAN，列表也会明确显示该范围。编辑表单使用分割线区分本地信息与对端信息。登记状态只提供正常（up）和停用（disabled），列表分别显示绿色“✓ 正常”和橙色“⏸ 停用”。新建隧道默认停用；旧版异常或未登记状态显示“? 待确认”，保留原登记含义，编辑时需重新确认正常或停用。模板也可填写中文“正常”“停用”。可维护本地网关、两个隧道的对端网关与登记状态。列表中的本地、对端网段只显示“用途 - CIDR”；手填对端网段显示“网段备注 - CIDR”，不附加 VLAN ID 或网关。关联 VLAN 的用途和网段实时带出，手填网段独立保留。

## 导入导出

模板版本为 ledger-8。每类台账下载自己的最新 XLSX 模板，不修改表头、工作表或版本。旧版模板请重新下载后按列填写。

每个字段独占一列，不再把多个字段拼在一个单元格。VLAN 的 CIDR、网关、网段用途、网段编号分别占列，同一 VLAN 有多个网段时逐行填写。Wi-Fi、AWS 的关联网络范围、VLAN ID、网段 CIDR 分别占列；AWS 两端按各自区域匹配。手动对端 CIDR 和备注分别占列。备注可以直接包含竖线或换行，无需额外引号。

新增记录编号留空，系统生成；更新保留导出编号并选择更新模式。同一条资料的多行保留相同记录编号。新增多行资料在“导入分组”填写相同自定义值，如 A001，不同资料使用不同分组；单行可不填。VLAN 还支持按相同区域、网络范围和 VLAN ID 自动合并。公共字段只需填写首行，续行留空；重复填写时必须一致，否则整条资料报错。网段编号与接入编号新增留空，更新保留以维持引用和密码。

月租费用为整条带宽线路的共享字段；主线和赠送线路的线路号、带宽使用各自列。线路接入明细每条接入占一行，接入编号、所属线路、连接方式、IP、掩码、网关、接口、拨号账号、拨号密码、用途分别占列。所属线路支持 primary / gift 或主线 / 赠送线路；route、bridge、pppoe 分别对应路由、桥接、拨号，也支持中文。两个隧道的网关、登记状态各自占列。多种明细同时存在时每种明细在一行填一条，不需要两两组合。

更新明细时需保留该资料的完整明细行；某个明细的首列填写 __CLEAR__ 可清空整个集合，不能与同组其他明细混填。导出没有明细的资料会带上该标记，确保再次导入时仍为空。模板中的“填写说明”提供具体规则。

各类密码导出留空。更新留空保留原密码，__CLEAR__ 明确清空；接入密码按接入编号匹配保留。上传后先预览校验，再确认写入；默认整批提交或整批回滚。只有主线的数据导入时不会自动增加赠送线路。

## 权限与备份

沿用资源模块的查看、新增、编辑、删除、导入、导出权限及数据范围。五类台账不对未登录访客或无资源查看权限的员工公开。

密码在数据库及导入暂存中加密，按记录查看权限读取。部署密钥沿用 data/business/wifi-secrets.key，需和数据库一起备份。现有表、记录 ID 和工单引用保留，不需额外执行数据库结构迁移。

已有整 VLAN 引用暂保留原来的全部网段，可在编辑页逐项调整。按具体网段保存后，后续新增其他网段不会自动加入该引用。修改 CIDR 时保留原网段编号，已有引用跟随该网段更新；被引用的网段不能直接移除，须先调整关联资料。

删除网段使用独立接口并校验当前记录版本、网段编号、删除权限及网段引用。删除不会改动其他网段、区域、VLAN ID、备注或同 VLAN 其他网段的 Wi-Fi / AWS 引用；操作写入独立审计记录。
