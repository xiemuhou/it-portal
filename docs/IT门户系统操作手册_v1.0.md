# IT 门户与运维管理系统操作手册

版本：v1.0  
日期：2026-10-21  
适用对象：公司员工、IT 运维人员和系统管理员

## 1 使用说明

系统部署后通过管理员提供的内网地址访问，例如 `https://portal.example.local/`；未配置反向代理时也可能使用 `http://服务器IP:8089/`。建议使用当前版本的 Edge 或 Chrome，并使用桌面电脑访问。

用户实际看到的菜单由角色权限决定。手册中某个菜单没有显示时，请联系管理员检查账号状态、角色和对应操作权限。

## 2 公共功能

### 2.1 查看服务概览

打开首页后可以查看公告、常用知识、IT 服务范围和相关入口。首页内容不要求登录。

### 2.2 查看公告

1. 点击左侧“公告”。
2. 点击公告标题查看正文、发布人和发布时间。
3. 有附件时，可点击“查看”在新窗口打开，或点击“下载”保存附件。
4. 已过截止时间、已撤下或草稿公告不会出现在公开列表。

### 2.3 查看知识库

1. 点击“知识库”。
2. 使用关键词查找文章。
3. 点击阅读后，系统在新窗口打开原文件或连续阅读页面。
4. 阅读页面不提供门户翻页按钮和源文件下载按钮，可直接使用浏览器滚动查看。

### 2.4 查看服务目录

点击“服务目录”查看 IT 可以处理的服务类型、适用范围、服务时间和申请说明。需要 IT 处理时，使用“提交工单”。

### 2.5 网络运维态势

点击“网络运维态势”后，系统在新窗口打开现有监控系统。监控系统是否要求再次登录，由监控系统自身决定。

## 3 登录和账号

### 3.1 登录

1. 点击页面右上角“账号登录”。
2. 输入管理员提供的账号和密码。
3. 点击“登录”。

连续空闲超过 10 分钟或会话达到 8 小时后，需要重新登录。

### 3.2 修改本人密码

1. 登录后点击右上角“修改密码”。
2. 输入当前密码和新密码。
3. 新密码至少 8 位。
4. 保存后原会话失效，使用新密码重新登录。

### 3.3 退出

点击右上角“退出”。在公共电脑上使用后必须退出并关闭浏览器窗口。

## 4 员工提交和跟进工单

### 4.1 提交工单

1. 点击“提交工单”。未登录时先完成登录。
2. 填写问题描述，尽量说明发生时间、现象、影响范围和已经尝试的操作。
3. 根据需要补充标题、区域、位置和联系方式。
4. AI 助手已启用时，可直接输入问题，或点击“使用问题描述”把左侧描述带入聊天框。不要在对话中填写密码、验证码或访问令牌。
5. AI 会给出排查建议，并列出匹配到的已发布操作手册。聊天只在当前页面临时保留。
6. AI 未解决问题或暂时不可用时，仍可直接提交工单。
7. 点击“提交工单”。不要连续重复点击。

提交成功后系统生成工单号，并进入待接单状态。

### 4.2 查看工单

普通员工进入“我的工单”，IT 进入“工单工作台”。列表显示工单号、标题、提交人、部门、状态、负责人和提交时间。

可使用关键词和状态筛选。页面默认每页 10 条，可切换 10、20 或 50 条，并可跳转到指定页。

### 4.3 留言和附件

1. 打开工单详情。
2. 在“处理记录与留言”填写补充信息。
3. 点击“发送留言”。
4. 添加附件时点击“添加附件”，选择 PNG、JPG 或 PDF，单个文件不能超过 20 MB。

关闭后的工单仍可留言。IT 的内部备注不会向工单发起人显示。

### 4.4 重开工单

问题再次出现时，打开已关闭工单并点击“重开”。系统建立新的处理轮次，原来的处理历史不会被覆盖。

## 5 IT 处理工单

### 5.1 接单

1. 在“工单工作台”打开待接单工单。
2. 确认问题内容和申请人信息。
3. 点击“接单”。

接单后状态变为处理中，并自动记录开始时间。多人同时点击时只有一人能够成功。

### 5.2 分配和转派

- 待接单工单可使用“分配”选择负责人，此时还不开始计时。
- 处理中工单可使用“转派”选择同事。系统结束原处理人的分段，并从同一时间开始新处理人的分段。
- 处理人下拉只显示具有工单处理权限的有效账号。

### 5.3 关闭工单

1. 打开处理中工单。
2. 点击“关闭”。
3. 选择问题分类。
4. 选择实际结束时间。结束时间必须晚于工单提交时间。
5. 根据需要填写处理说明。
6. 确认关闭。

列表和详情中的关闭时间显示到分钟。处理历时是工单流程时间，其中可能包含等待时间，不代表实际人工工时。

### 5.4 取消和纠正

- 工单无需继续处理时，使用“取消”并填写原因。
- 已关闭工单的分类或结束时间错误时，具备纠正权限的人员使用“纠正”，填写原因后保存。
- 纠正操作会重新计算处理区间并写入审计记录。

### 5.5 运维分类汇总

点击“运维分类汇总”，选择开始和结束日期后查询。页面显示关闭轮次、唯一工单数、总和平均处理历时、分类分布、当前状态及处理人记录。

“最终结单次数”归最后责任处理人；“参与轮次”和“本人区间历时”体现多人协作过程。

## 6 站内消息和快捷链接

### 6.1 站内消息

右上角铃铛数字表示未读消息数。

1. 点击铃铛进入消息列表。
2. 点击单条消息可进入关联公告或工单。
3. 点击单条“已读”处理一条消息。
4. 点击“一键已读”将当前全部未读消息标记为已读。

### 6.2 快捷链接

点击“快捷链接”，选择所需内部系统。链接在新窗口打开。普通员工只看到通用链接，IT 和管理员还可看到 IT 管理链接。

管理员可在快捷链接页面新增、编辑、启停和删除链接。URL 没有协议时系统自动补充 `http://`。

## 7 五类基础信息台账

进入“基础信息台账”，通过上方标签切换 VLAN 规划、Wi-Fi 规划、网络设备、带宽线路和 VPN 隧道。列表可按关键词和区域筛选，VLAN 还可按 VLAN ID 排序。

### 7.1 通用操作

1. 点击相应模块的“新增”。
2. 填写区域和业务字段。
3. 根据实际状态设置“启用”。
4. 保存。

编辑时系统检查版本。若其他人已经修改，刷新页面后重新核对。删除前先解除其他资料对该记录的引用。

### 7.2 VLAN 规划

1. 选择区域，填写 VLAN ID。
2. 点击“添加网段”。
3. 对每个网段填写规范 CIDR、网关和网段用途。
4. 需要管理具体静态 IP 时，勾选该网段的“静态 IP 管理”。
5. 同一个 VLAN 可继续添加多个网段。
6. 保存后列表按网段逐行展示。

删除单个网段时使用网段对应的删除入口。被 Wi-Fi、VPN 隧道或静态 IP 使用时，系统会阻止删除。

### 7.3 Wi-Fi 规划

1. 选择区域，填写 SSID、用途和覆盖位置。
2. 选择不认证、密码或密码加 MAC。
3. 需要密码时填写密码；编辑时留空表示保留原密码。
4. 添加关联 VLAN 网段。下拉项包含区域、VLAN ID、CIDR 和用途。
5. 按需关联 AP，设置启用状态和备注后保存。

密码属于敏感信息，只在授权页面按需查看，不会出现在导出文件中。

### 7.4 网络设备

按以下顺序登记：区域、设备类型、设备型号、ESN、上联设备、上联接口、本机接口、管理 IP、用户名、密码、安装位置、堆叠、维保信息、启用和备注。

上联设备只按管理 IP 选择和显示。上联设备接口和本机上联接口分别填写，不能互相替代。堆叠设备勾选“是否堆叠”即可，不填写堆叠说明。

### 7.5 带宽线路

1. 选择区域，填写运营商和保障电话。
2. 在运营商后填写整条线路的月租费用，再点击“添加主线或赠送线路”，填写线路类型、线路号和上下行带宽。
3. 点击添加接入明细，为每个 IP 或接入方式分别登记连接方式、接口和用途。
4. 路由或桥接可填写 IP、掩码和网关；拨号依次填写拨号账号、拨号密码和用途。
5. 填写光猫管理账号密码、到期时间、启用和备注。

一条线路有多个 IP 时，每个 IP 建立独立接入明细，不要把多个地址写进同一个输入框。

### 7.6 VPN 隧道

1. 选择本地区域和本地 VLAN 网段。
2. 填写本地网关。
3. 选择对端区域和对端 VLAN 网段。
4. 对端资料不在 VLAN 规划中时，手工添加对端 CIDR 和备注。
5. 添加最多两个隧道，填写对端网关并选择正常或停用。
6. 保存。

列表中的对端网段使用“用途或备注 - CIDR”显示。

### 7.7 台账导入导出

1. 在对应台账点击“下载模板”。
2. 按模板每列填写，不改变表头。
3. 网络设备上联设备只填写管理 IP。
4. 上传文件后先查看预览和错误信息。
5. 无错误时确认提交；存在错误时默认先修改文件，也可在有权限时明确选择只提交正确行。
6. 导出只包含当前权限范围，并排除密码明文。

## 8 静态 IP 管理

### 8.1 启用受管网段

先在 VLAN 规划编辑网段，勾选“静态 IP 管理”。只有已勾选的网段会出现在静态 IP 管理的网段下拉中。

### 8.2 登记 IP 占用

1. 进入“静态 IP 管理”。
2. 选择“区域 + VLAN ID + 网段”。
3. 查找目标 IP，点击编辑。
4. 选择占用状态和确认状态。
5. 个人使用时选择系统人员，部门自动带出。
6. 公共设备选择公共归属，不需要使用人；可以选择“管理/使用部门”，该部门独立于人员；已占用或冲突时要填写设备类型。
7. 选择笔记本、台式机，或手工填写打印机、门禁、服务器等设备类型。
8. 根据需要填写 MAC、位置和备注，保存。

### 8.3 关联电脑

1. 在 IP 编辑页面选择电脑资产。
2. 选择该电脑的具体网卡。网卡选项显示网卡类型和 MAC。
3. IP 记录的 MAC 必须与所选网卡 MAC 一致。
4. 保存后，电脑台账会显示该 IP。

如果 MAC 相同但使用人、部门、位置或设备类型不同，系统显示“资料不一致”，不会自动覆盖原资料。请核实后在正确的数据源中修改。

### 8.4 释放 IP

在 IP 列表点击“释放”。释放会清除当前使用人、电脑、网卡和占用信息，但保留历史记录。网关等系统保留地址不能释放或编辑。

### 8.5 检查未关联电脑的记录

使用“资产关联”或“资料一致性”筛选，查看电脑类设备未关联资产、未确认设备类型或资料冲突的 IP。打印机、门禁和服务器等非电脑设备允许不关联电脑台账。

### 8.6 导入导出

下载静态 IP 模板后，按区域、VLAN ID、网段、IP 地址、归属类型、部门、使用人、占用设备、MAC 地址、位置、备注、状态、确认状态的顺序填写。状态留空默认为空闲，确认状态留空默认为待确认。

- 个人使用记录的部门由使用人自动带出，Excel 部门与人员部门不一致时不能导入。
- 公共设备的“部门”表示管理/使用部门，可以填写系统部门，也可以留空，不要求填写使用人。
- 公共设备填写的部门在系统中不存在或名称不唯一时仍可导入；系统保留原始名称，显示“部门不存在”并自动设为待确认。管理员进入 IP 编辑页面选择正确部门后，可将其改为已确认。
- 当前网段导出包含全部可登记 IP；未登记地址以“空闲 / 待确认”输出，网段地址、广播地址和系统网关不导出。

## 9 电脑设备台账

### 9.1 新增电脑

1. 进入“电脑设备台账”，点击新增。
2. 填写资产编号；不填写时系统可自动生成。
3. 设备类型选择笔记本或台式机。
4. 按年月填写验收日期。系统按当前月份自动计算使用年限，精确到年和月；超过 5 年时列表使用深色标识。
5. 选择个人使用或公共设备。
6. 个人使用时选择使用人，部门自动带出；公共设备无需使用人和部门。
7. 选择区域，按需填写位置、操作系统、状态和备注。
8. 添加网卡，每行选择网卡类型并填写 MAC。
9. 添加配件，每行填写配件类型和备注。
10. 如需占用静态 IP，选择 IP 并关联对应网卡。
11. 保存。

### 9.2 维护网卡和配件

- 网卡只记录类型和 MAC；点击行末“移除”删除该行。
- 配件只记录类型和备注；品牌、型号或序列号可写入备注。
- 删除仍被静态 IP 使用的网卡前，应先解除 IP 关联。

### 9.3 查看变更记录

打开电脑详情和历史记录，可查看使用人、部门、位置、配件以及 IP/网卡关系的前后变化。例如“使用人：张三 → 李四”。

### 9.4 删除电脑

电脑没有静态 IP 关联时，可以执行删除并填写原因。存在关联时，先在静态 IP 管理中释放或解除关系。

### 9.5 导入导出

使用电脑设备标准模板。验收日期填写为 `YYYY-MM`。一个电脑有多块网卡、多个 IP 或多个配件时，可以使用多行，资产编号保持相同。IP 必须与同一行或同一资产组中的 MAC 对应。

## 10 耗材管理

耗材管理用于登记硒鼓、墨盒、鼠标、键盘、存储介质等低值易耗品。管理员和 IT 运维人员可以维护耗材、办理入库和出库并查询完整流水。

### 10.1 建立耗材目录

1. 进入“耗材管理”，点击“新增耗材”。
2. 填写名称、分类、规格、计量单位和最低库存；耗材编码留空时由系统生成。
3. 当前库存小于或等于最低库存时，列表显示库存预警。
4. 不再使用的耗材可设为停用。停用后保留历史流水，但不能继续入库或出库。
5. 没有任何出入库流水的耗材品类可直接删除；已有流水时系统会阻止删除，请改为停用。

### 10.2 采购入库

在耗材列表点击“入库”，填写入库日期、数量、采购单价、供应商和备注。入库不需要填写单据编号。保存后库存立即增加，并纳入所选月份的入库统计。

### 10.3 领用出库

在耗材列表点击“出库”，填写数量、出库日期和用途，并按实际情况选择以下一种领用方式：

- 关联电脑：选择电脑后，系统自动带出该电脑的使用人和部门；该记录也会显示在电脑详情的“耗材领用记录”中。
- 人员或部门领用：不关联电脑，直接选择领用人员或部门。
- 其他对象领用：打印机、会议室和公共设备等可在“其他领用对象”中填写。

出库数量不能超过当前库存。流水记录保存后不能直接覆盖，避免库存历史失真。

- 出库需要退回时，在流水中点击“返库”并填写原因；系统恢复库存，原流水标记为已处理。若原出库关联了电脑，该耗材不再显示在电脑的配件领用记录中。
- 入库录入错误时，在流水中点击“撤销入库”并填写原因；系统扣回原入库数量。当前库存不足时不能撤销，须先完成相关耗材返库。
- 每笔原始入库或出库只能返库或撤销一次，反向流水不能再次操作。

### 10.4 查询库存与流水

耗材列表显示当前库存、本月入库、本月出库和最低库存。可按名称、编码、分类或规格搜索，也可切换统计月份。点击“流水”查看采购入库、领用出库、出库返库和入库撤销记录，包括日期、数量、单价、领用对象、用途、单据编号、备注和操作人。

## 11 IT 备忘录

IT 备忘录用于保存零散的系统地址、账号和说明，不用于发布公告、处理工单或保存操作手册。

1. 进入“IT 备忘录”，点击“新增备忘录”。
2. 填写标题、分类、系统或设备地址、用户名、标签和备注。
3. 密码必须填写在专用密码栏，不要写入备注。密码使用部署凭据密钥加密，保存后不会在编辑页面回显。
4. 所有备忘录仅管理员和 IT 人员可见，不提供个人私有或其他可见范围选项。
5. 点击“查看密码”后系统单独解密；关闭窗口后页面清除本次显示结果，系统不记录密码查看人和查看时间。
6. 其他人不能编辑或删除创建人保存的记录。创建人删除记录时，系统同时清除对应密文并保留删除操作审计。

列表和搜索接口不返回密码，也不会按密码内容搜索。备忘录不提供包含密码的导入或导出功能。

## 12 管理员操作

### 12.1 部门与人员

菜单包含部门、人员和岗位标签。

- 部门：可新增、编辑、启停和删除；上级部门显示中文名称。
- 人员：显示账号、姓名、所属部门、最上级部门、岗位、角色、来源和状态；支持部门筛选。
- 岗位：按名称维护，不固定绑定部门。
- 来源为 EHR 或 LDAP 的记录带有明确标识；在门户删除不会删除 EHR 或域目录数据，仍存在于外部目录的人员会在下次同步时重新导入。

删除人员前应先处理其未完成工单、电脑资产和静态 IP 责任关系。系统对有历史记录的用户执行身份匿名化，保留业务历史。

人员列表支持按关键词、部门、账号状态和数据来源组合筛选。账号状态包括启用、停用；数据来源包括 EHR 同步、LDAP 同步、手工维护。点击“重置”可清除全部筛选条件。

### 12.2 EHR 同步

1. 进入“部门与人员”。
2. 查看最近同步状态和错误提示。
3. 点击“同步 EHR”。
4. 等待后台完成后刷新页面查看结果。

### 12.3 LDAP / Active Directory 同步

1. 部署管理员先在服务器的 `business.local.json` 配置 LDAP 只读连接并重启门户。配置文件中的服务账号密码只能保存在受控服务器上，不得写入普通代码交付包或操作文档。
2. 进入“部门与人员”，点击“同步域用户”。
3. 在状态窗口核对服务器、Base DN、TLS 证书验证、自动同步时间和最近同步结果。
4. 首次使用先点击“测试连接”。测试只读取最多 5 条用户样本，不写入门户或域目录。
5. 点击“开始同步”后任务在后台执行。同步完成后刷新部门、人员和岗位列表，来源显示为“LDAP同步”。
6. 新增域用户默认停用。管理员核对部门、岗位和角色后，在人员编辑中启用账号。
7. 已禁用的域账号会停用对应门户账号；域中重新启用不会自动启用门户账号，避免绕过管理员确认。
8. LDAP 同步不修改门户密码和角色。当前登录仍使用门户账号密码，不使用域密码。

系统每天 00:00 自动同步。EHR 连接只读，门户不会修改 EHR 数据。后续新增员工默认停用，管理员核实后再启用。

### 12.4 用户管理

新增人员时填写账号、姓名、部门、岗位、联系方式、角色和初始密码。初始密码留空时由系统生成，并只在当前交付窗口显示。

管理员可编辑账号资料、启停账号、分配角色和设置新密码。人员选择后，使用其资料的电脑和 IP 表单自动带出部门。

### 12.5 角色与权限

1. 进入“角色与权限”。
2. 新增或选择角色。
3. 勾选模块操作权限。
4. 对需要数据范围的权限选择本人、当前负责、区域、部门或全部。
5. 选择区域或部门范围时继续选择具体项目。
6. 保存后，用户下一次请求使用新权限。

不要只根据菜单是否显示判断权限。系统以服务端校验结果为准。

### 12.6 工单分类和服务目录

“基础资料”只保留工单分类和 IT 服务目录。

- 工单分类：维护结单分类和启用状态。已被使用的分类不能删除，可以停用。
- IT 服务目录：维护服务名称、说明、服务时间、联系渠道和是否公开发布。

安装位置、供应商和运营商、基础字典、改善成果已经从基础资料入口移除。

### 12.7 公告管理

1. 进入“公告管理”，点击新增。
2. 填写标题、正文、置顶和可选截止时间。
3. 在草稿状态上传附件。
4. 保存后检查内容，再点击“发布”。
5. 发布后所有有效账号收到站内消息。
6. 修改附件时先撤下公告，编辑完成后重新发布。

可按草稿和已发布筛选。管理列表显示发布时间和截止时间，截止时间精确到分钟。

### 12.8 知识管理

1. 进入“知识管理”，点击上传。
2. 选择分类，填写标题并选择 HTML、PDF、PPT 或 PPTX 文件。
3. 保存为草稿后检查预览。
4. 预览正常后发布。
5. 更新内容时上传新版本，不覆盖旧文件。
6. 不再使用时撤下或删除。

PPT/PPTX 转换失败时，检查文件是否损坏、是否有密码，以及服务器是否安装可用的 PowerPoint 或 LibreOffice。

### 12.9 快捷链接管理

在“快捷链接”页面使用管理按钮新增或编辑。分类选择通用或 IT 管理，填写标题、URL、图标文字、说明、启用状态和排序。停用后链接不再向用户显示。

### 12.10 操作审计

进入“操作审计”查看时间、操作者、动作、对象类型和结果。审计用于追踪授权、业务变更、发布、导入、同步、删除和备份，不显示密码明文。

AI 配置变更和连接测试会记录操作结果，但不会记录 API 密钥或员工对话正文。

### 12.11 AI 助手设置

1. 进入“管理中心 → AI 助手设置”。
2. 填写 OpenAI 兼容 API 的基础地址或完整 Chat Completions 地址和模型名称。DeepSeek 可填写 `https://api.deepseek.com`，系统会自动补齐请求路径。
3. 使用 DeepSeek 官方地址并保存密钥后，可点击“查询余额”实时查看账号余额。该按钮仅管理员可用，查询结果不保存到门户数据库。
4. 首次配置时填写 API 密钥。页面显示“已安全配置”后，后续保存可留空以保持原密钥。
5. 设置请求超时、知识库推荐数量和系统提示词。
6. 选择回答模式：严格知识库、混合模式或通用 IT 助手。推荐使用“混合模式”。
7. 选择知识库没有匹配内容时提供安全的通用建议，或直接引导用户提交工单。
8. 勾选启用并保存，再点击“测试已保存配置”。
9. 需要更换密钥时输入新密钥并保存；需要彻底移除时勾选“清除当前 API 密钥”。

严格模式或“直接引导提交工单”在没有知识依据时不会调用外部 AI。AI 回答页面会标明依据知识库、通用建议或未找到知识依据。API 密钥在服务器本地加密保存，页面不回显。AI 调用失败不影响工单提交。

### 12.12 数据库备份说明

门户不提供数据库备份或恢复菜单。SQL Server数据库由管理员通过SQL Server Agent、维护计划或企业备份平台自动备份；门户操作账号不需要备份与恢复权限。

数据库备份不包含知识文件、公告附件、工单附件和密码加密密钥，文件目录必须由文件备份工具另行保护。数据库迁移和灾难恢复按《数据库与门户迁移恢复手册》执行。

## 13 常见问题

### 13.1 显示数据库不可用

先点击重新加载。若多个页面同时出现该提示，记录发生时间和操作页面，联系系统管理员检查 SQL Server 服务、网络连通性和应用日志。不要连续重复提交写操作。

### 13.2 找不到菜单或按钮

菜单按权限显示。确认账号处于启用状态，并由管理员检查角色是否包含相应模块和操作权限。

### 13.3 下拉框找不到人员或部门

在下拉搜索框输入中文名称或账号。仍找不到时，检查人员是否启用、是否属于已同步部门，并查看最近 EHR 同步结果。

### 13.4 IP 无法关联电脑

核对电脑区域、所选网卡和 MAC。只有 IP 记录 MAC 与电脑网卡 MAC 完全一致时才能关联。

### 13.5 无法删除 VLAN 网段或电脑

记录仍被其他业务使用。VLAN 网段需要先解除 Wi-Fi、VPN 隧道或静态 IP 引用；电脑需要先释放或解除静态 IP 关联。

### 13.6 公告没有出现在首页

检查公告是否已发布、发布时间是否有效、截止时间是否已过。草稿、撤下和过期公告不会公开显示。

### 13.7 知识文件无法阅读

检查文件格式和大小。PPT/PPTX 还需要服务器转换组件。管理员可在知识管理中查看预览状态并重新上传有效文件。

## 14 管理规范

- 不在备注、导入模板或截图中保存数据库密码、域账号密码和系统密钥。
- 修改 VLAN、线路、隧道、电脑和 IP 前先核对关联影响。
- 停用人员前处理未完成工单、电脑和 IP 责任关系。
- 定期检查待确认和资料不一致的 IP、已停用设备、到期线路和同步错误。
- 数据库、附件和加密密钥必须按同一恢复批次备份，并定期执行恢复演练。
